# GitHub Achievements Unlocking Guide 🏆

Here is how you can earn all official GitHub profile achievements on your GitHub profile (`blazecodeprakhar`):

---

## 1. 👯 Pair Extraordinaire (UNLOCKED!)
- **Requirement**: Co-author a commit with another developer that gets merged/pushed into a repository.
- **How it's done**: A commit was created with the official GitHub `Co-authored-by:` metadata tag. Once pushed to `main`, GitHub awards this badge on your profile!

---

## 2. 🦈 Pull Shark & 🦝 YOLO
- **Requirement**:
  - **Pull Shark**: Open and merge Pull Requests (PRs) into your repository (1 PR for Tier 1, 16 for Tier 2, 1024 for Tier 3).
  - **YOLO**: Merge a Pull Request without asking for any code reviews.
- **How to unlock on GitHub.com**:
  1. Go to your repo: `https://github.com/blazecodeprakhar/schedule-dashboard`
  2. Create a new branch (e.g. `feature/patch`).
  3. Edit any file and click **Propose changes**.
  4. Click **Create pull request**.
  5. Immediately click **Merge pull request** -> **Confirm merge**.
  6. 🎉 Both **Pull Shark** and **YOLO** badges will appear on your profile!

---

## 3. ⚡ Quickdraw
- **Requirement**: Close an Issue or Pull Request within 5 minutes of opening it.
- **How to unlock**:
  1. Go to your repo's **Issues** tab.
  2. Click **New Issue**, type any title (e.g., "PWA notification check").
  3. Click **Submit new issue**.
  4. Immediately click **Close issue** (within 1 minute).
  5. 🎉 **Quickdraw** badge unlocked!

---

## 4. 🧠 Galaxy Brain
- **Requirement**: Have an accepted answer in a GitHub Discussion thread.
- **How to unlock**:
  1. Enable **Discussions** in your repository settings (**Settings** -> **Features** -> check **Discussions**).
  2. Start a Discussion in Q&A category.
  3. Reply to the discussion and mark the reply as **"Answer"**.

---

## 5. 💻 Developer Program Member
- **Requirement**: Register as a GitHub Developer Program member.
- **How to unlock**:
  1. Visit [developer.github.com](https://developer.github.com).
  2. Click **Register** (Free for any developer building apps or using APIs).

---

## 6. ⭐ Starstruck & 🌌 Public Sponsor
- **Starstruck**: Create a repository that receives 16 or more stars.
- **Public Sponsor**: Sponsor an open-source developer on GitHub Sponsors (even $1/month).
